# OrCAD + Allegro 17.4 英语学习与自测应用

## 内容
- OrCAD Capture 17.4：259 条菜单路径
- Allegro PCB Editor 17.4：286 条菜单路径
- 补充设置窗口字段：20 条
- 从原 Word 文档提取的 Capture 菜单截图：13 张

## Windows PC 快速打开
1. 解压整个 ZIP 文件。
2. 双击 `index.html`，即可在新版 Chrome、Edge 或 Firefox 中运行基础功能。
3. 英语朗读由浏览器 / 操作系统提供；如果没有英语声音，请安装英语语音包或改用 Chrome / Edge。
4. 学习进度保存在当前浏览器本地。

## PC 启动本地网页服务
双击 `start_pc.bat`，然后访问 `http://localhost:8765`。在 localhost 下可以注册 Service Worker 并缓存资源。

## 手机运行
### 方法 A：手机和电脑连接同一个 Wi-Fi
1. 在电脑上双击 `start_phone_lan.bat`。
2. 在电脑命令窗口或运行 `ipconfig` 找到电脑的 IPv4 地址，例如 `192.168.1.20`。
3. 手机浏览器访问 `http://电脑IPv4地址:8765`，例如 `http://192.168.1.20:8765`。
4. 电脑服务窗口需要保持运行。Windows 防火墙若询问，请允许专用网络访问。
5. 该局域网 HTTP 方式可运行学习、自测和朗读；浏览器是否允许安装 PWA 取决于其安全策略。

### 方法 B：安装为手机主屏幕应用（推荐）
将解压后的整个文件夹部署到支持 HTTPS 的静态网站空间（例如 GitHub Pages、Cloudflare Pages 或自有 HTTPS 网站），手机用 Safari / Chrome 打开网址：
- iPhone：Safari 分享按钮 → 添加到主屏幕。
- Android：Chrome 菜单 → 安装应用 / 添加到主屏幕。
首次打开后，Service Worker 会缓存应用资源，之后可离线学习。
本应用是静态网页，不需要登录，也不会把答题记录上传到服务器。

## 功能
- 英文菜单路径朗读，可选英语声音和语速。
- 英文题目 + 4 个中文选项；提交后显示正确答案、菜单路径、功能说明和资料依据。
- 收藏、错题本、学习标记、正确率统计。
- 搜索英文、中文、菜单路径和功能说明。
- 查看原始 Word 文档中的 13 张 Capture 截图。
- 可导出本机学习记录 JSON。
